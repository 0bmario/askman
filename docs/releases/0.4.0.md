# Askman 0.4.0 release notes

Status: release preparation only. The release gate and native Linux/macOS/Windows
evidence are still pending; this note does not authorize tagging or publication.
All README, release-note, workflow, and package metadata must be finalized before
evaluation; after evaluation, only `release-gate.json` and the release-gate summary
may change before tagging.

Planned release contents:

- Hybrid lexical+dense retrieval over a pinned four-platform `tldr-pages`
  snapshot, with deterministic bundle validation and rollback-safe activation.
- Self-contained native archives with pinned ONNX Runtime 1.20.0 and checksums.
- Crates.io packaging contains executable source only; production database,
  model, model cache, and mutable runtime assets remain separate release assets.

Evidence and limits:

- No GitHub release or crates.io publication has occurred.
- The checked-in matching-bundle evidence is dev-only and ineligible for
  promotion until a clean rebuild and native matrix verification pass.
- [Production bundle procedure and dev evidence](../reproducibility/production-bundle.md)
- [Dense retrieval benchmark](../reproducibility/artifacts/dense-strategy-benchmark-v1.json)
- [Inconclusive release-gate comparison](../reproducibility/artifacts/release-gate-comparison-v2.json)
- [Cross-platform verification procedure](../reproducibility/ci.md)
