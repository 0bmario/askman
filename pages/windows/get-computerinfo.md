# Get-ComputerInfo

> Get system and operating system properties in one object.
> Note: This command can only be used through PowerShell.
> See also: `systeminfo`.
> More information: <https://learn.microsoft.com/powershell/module/microsoft.powershell.management/get-computerinfo>.

- Show all system and operating system properties:

`Get-ComputerInfo`

- Show all version properties:

`Get-ComputerInfo -Property "*version"`
